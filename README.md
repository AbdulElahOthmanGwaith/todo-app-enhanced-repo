## 🇬🇧 English

### About
Smart Todo List is a Progressive Web App (PWA) designed to help you manage your daily tasks efficiently. Built with modern web technologies, it works offline, can be installed on any device, and provides a seamless user experience.

### Features
- ✅ **Offline Support** - Works without internet connection
- 📱 **Installable** - Install on home screen of any device
- 🏷️ **Categories** - Organize tasks by Work, Personal, Study, Health
- 📊 **Priorities** - Set task priorities (Low, Normal, High, Urgent)
- 📅 **Due Dates** - Set and track task deadlines
- 🔍 **Smart Search** - Find tasks instantly
- 🌙 **Dark Mode** - Easy on the eyes, day or night
- 📈 **Statistics** - Track your productivity
- 🔄 **Export/Import** - Backup your data
- ↩️ **Undo Delete** - Recover deleted tasks

### Live Demo
🌐 **Visit:** [https://2bc7do14qaf0.space.minimax.io](https://2bc7do14qaf0.space.minimax.io)

### Installation
1. Open the website in a modern browser (Chrome, Edge, Firefox, Safari)
2. On Desktop: Click the install icon in the address bar
3. On Mobile: Tap "Add to Home Screen" from the menu
4. Enjoy your offline-capable todo app!

### Technology Stack
- **HTML5** - Semantic markup
- **CSS3** - Modern styling with CSS Variables
- **JavaScript (ES6+)** - Vanilla JS with modern features
- **Service Worker** - For offline functionality
- **Web App Manifest** - For PWA installation
- **Local Storage** - Data persistence

### Local Development
```bash
# Clone the repository
git clone https://github.com/[username]/todo-app-enhanced.git
cd todo-app-enhanced

# Open in browser
# Simply open index.html in your browser
# Or use a local server:
npx serve .
```

## 🇸🇦 العربية

### نبذة عن التطبيق
قائمة المهام الذكية هو تطبيق ويب تقدمي (PWA) صُمم لمساعدتك في إدارة مهامك اليومية بكفاءة. بُني باستخدام تقنيات الويب الحديثة، ويعمل بدون إنترنت، ويمكن تثبيته على أي جهاز، ويوفر تجربة مستخدم سلسة.

### المميزات
- ✅ **دعم العمل بدون إنترنت** - يعمل حتى بدون اتصال بالإنترنت
- 📱 **قابل للتثبيت** - ثبّت على الشاشة الرئيسية لأي جهاز
- 🏷️ **تصنيفات** - نظّم المهام حسب العمل، الشخصي، الدراسة، الصحة
- 📊 **أولويات** - حدد أولويات المهام (منخفضة، عادية، مهمة، عاجلة)
- 📅 **تواريخ الاستحقاق** - حدد وتابع مواعيد الاستحقاق
- 🔍 **بحث ذكي** - ابحث عن المهام بشكل فوري
- 🌙 **الوضع الداكن** - سهل على العين ليلاً ونهاراً
- 📈 **إحصائيات** - تابع إنتاجيتك
- 🔄 **تصدير واستيراد** - احتفظ بنسخة احتياطية من بياناتك
- ↩️ **تراجع عن الحذف** - استعد المهام المحذوفة
